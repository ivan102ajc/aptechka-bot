# 💊 Аптечка — Telegram-бот для тех, кто принимает лекарства

<img src="avatar.png" width="120" align="right" alt="">

Бот напоминает принять лекарство, следит за сроками годности, находит ближайшие аптеки и подсказывает аналоги.
Работает бесплатно: на своём компьютере или круглосуточно в Yandex Cloud в пределах бесплатных лимитов.

## Возможности

- ⏰ **Напоминания о приёме** с кнопками «Принял» и «Через 15 мин», история приёма за 30 дней
- 📅 **Сроки годности**: предупреждение за месяц, за неделю и когда срок истёк
- 📍 **Аптеки рядом** по геолокации или адресу: бот определяет ваш адрес, отмечает аптеки в вашем доме и на вашей улице, показывает направление, время пешком и часы работы
- 🔄 **Аналоги**: 220 действующих веществ и 770 торговых названий, понимает названия с опечатками, латиницей и в английской раскладке («нурафен», «nurofen», «yehjaty» → Нурофен)
- 🩺 **Подсказки по симптомам**: безрецептурные средства при лёгких недомоганиях, а при опасных признаках совет звонить 103
- 💬 Понятные ответы на любые непонятные сообщения

> ⚠️ Бот не врач. Справочная информация не заменяет консультацию специалиста.

## Данные

Все источники бесплатные и не требуют ключей:
- карты и адреса: [OpenStreetMap](https://www.openstreetmap.org/) (Nominatim, запасные — Overpass и Photon);
- аналоги: собственный справочник `analogs.py`, сверять можно по [Госреестру лекарственных средств](https://grls.rosminzdrav.ru/).

## Запуск на своём компьютере (Windows)

1. Установите [Python 3.10+](https://www.python.org/downloads/) и отметьте «Add python.exe to PATH».
2. Создайте бота у [@BotFather](https://t.me/BotFather) командой `/newbot`, получите токен.
3. Скопируйте `token.example.txt` в `token.txt` и вставьте туда токен.
4. Дважды щёлкните `start.bat`.

Подробнее — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

## Круглосуточная работа в Yandex Cloud (бесплатно)

```
Telegram ──вебхук──▶ Cloud Function (cloud.handler) ◀──раз в минуту── Таймер
                            │
                            ▼
                Object Storage: medbot.db
```

- Сообщения Telegram сам присылает в функцию (вебхук). Адрес функция настраивает сама.
- Таймер раз в минуту запускает рассылку напоминаний и проверку сроков годности.
- База SQLite лежит в бакете: функция скачивает её только при изменениях и загружает обратно только если что-то поменялось.

**Бесплатные лимиты Yandex Cloud:** 1 млн вызовов функций и 10 ГБ×час в месяц. Таймер раз в минуту — это ~43 тыс. вызовов.

### Настройка

1. **Object Storage** → создать бакет (приватный), например `aptechka-db`. Если переносите бота с компьютера, загрузите в бакет свой `medbot.db`.
2. **Сервисный аккаунт** с ролями `storage.editor` и `functions.functionInvoker`.
3. **Cloud Functions** → создать функцию → сделать **публичной**.
4. Создать версию:
   - среда выполнения **Python 3.12**, способ — **ZIP-архив** из файлов `bot.py`, `cloud.py`, `analogs.py`, `symptoms.py`, `requirements.txt`;
   - точка входа `cloud.handler`, таймаут 60 с, память 256 МБ;
   - сервисный аккаунт — созданный выше;
   - переменные окружения: `BOT_TOKEN` (токен бота) и `BUCKET` (имя бакета).
5. В настройках масштабирования функции ограничить **1 экземпляр**, чтобы база не записывалась параллельно.
6. **Триггер → Таймер**, cron `* * * * ? *`, вызывает функцию от имени того же сервисного аккаунта.

Через минуту таймер сам подключит вебхук. После этого локальная версия на компьютере увидит, что бот работает в облаке, и запускаться не будет.

## Файлы

| Файл | Назначение |
|---|---|
| `bot.py` | Логика бота; запуск на компьютере (long polling) |
| `cloud.py` | Обёртка для Yandex Cloud Functions |
| `analogs.py` | Справочник аналогов и поиск с исправлением опечаток |
| `symptoms.py` | Подсказки по симптомам и список опасных признаков |
| `start.bat` | Запуск на Windows двойным щелчком |
